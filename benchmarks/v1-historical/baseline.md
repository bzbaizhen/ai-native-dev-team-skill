# V1 historical baseline

The two anonymous cases expose different failure modes:

| Case | Wall clock | Active Agent time | Implementation | QA | Governance and preparation | Main finding |
|---|---:|---:|---:|---:|---:|---|
| Case A: complex media workflow | 22.3h | 37–46h | 45–49% | 32–34% | 19–20% | implementation and QA outran integration into the stable branch |
| Case B: synthetic aggregation MVP | 59.7h | 44.8–57.4h | 13–17% | 19–23% | 32–40% plus product/research work | governance and preparation expanded before the user path passed |

Case A recorded 20 work threads, 20 task branches, 24 worktrees, complete team-Skill loading in all 20 worker threads, highest-tier model/reasoning in all 20, and first-shell-check failure in 18. The environment failure rate is disclosed but excluded from V2 attribution.

Case B found approximately 4–7 active Agent hours of compressible coordination, repeated state synchronization, and premature preparation. Valuable QA found real cross-platform and lifecycle defects, so QA time is not classified as waste.
