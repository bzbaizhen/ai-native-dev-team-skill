## English

Synchronizes the current local Skill packages into the canonical GitHub source.

- Team: use lightweight delegation for bounded work with concrete value; keep simple and tightly coupled work with the main agent. Main-agent takeover within existing scope preserves write ownership and required independent validation. Cost-saving claims need observed runtime mapping and pricing evidence.
- Router: replace the retired `gpt5.6` bundled profile with explicitly selected `gpt6` on `route/v2`. Use Astra medium for the control plane, Luna max for C0 batches, and Sol 6.1 low/medium/high for C1/C2/C3.
- R1/R2/R3 each use ONE Sol 6.1 assurance review at low/medium/high, including R3. Same-model review is reported and does not prove independent model validation. Unavailable routes block; unknown availability stays unknown.
- Remove the GLM/DeepSeek high-volume slot and fallback from `gpt6`; preserve safe project-local `route/v1` compatibility and its evidence-gated fallback. Old `gpt5.6` profile selections are rejected and need explicit migration.
- Update complete install inventories, bilingual documentation, packaging checks, and regression coverage to the current contracts.

Router decisions remain `enforcement_status: not-executed`. Offline tests and host metadata do not prove live provider availability, host adapter execution, or measured performance savings. This release does not overwrite existing host installations or other projects' configuration.

## 简体中文

将当前本地两个 Skill 的内容同步为规范源码版本：

- Team 按明确的任务边界和具体价值进行轻量委派；简单修改、强耦合工作由主 Agent 连续处理。主 Agent 在已有授权内接手时，先确定写入归属并保留必要的独立验证。成本节省需有实际模型与费用依据。
- Router 用显式选择的 `gpt6` 替换已退休的 `gpt5.6`。控制面使用 Astra medium，C0 batch 使用 Luna max，C1/C2/C3 使用 Sol 6.1 low/medium/high。
- R1/R2/R3 各进行一次 Sol 6.1 审核，强度依次为 low/medium/high，包括 R3。同模型审核会标注，不等于独立模型验证；路由不可用时阻断，未知时保持未知。
- `gpt6` 移除 GLM/DeepSeek 高吞吐槽位及回退，保留安全项目自定义 `route/v1` 兼容及其证据门控回退。旧 `gpt5.6` 配置需明确迁移。
- 同步安装清单、中英文说明、打包检查与回归测试。

Router 仍只返回 `enforcement_status: not-executed`。离线测试和宿主元数据不能证明供应商可用、宿主适配器已执行或实测节省。本次发布不覆盖已有宿主安装，不批量改写其他项目配置。
