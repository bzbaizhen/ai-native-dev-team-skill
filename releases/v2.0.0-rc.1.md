## Candidate changes

- route work before team formation: `no-delegation`, `single-worker`, `task-cell`, or `team-required`;
- route C0 batch / C1 / C2 / C3 execution to Economy-Low / Standard-Medium / Advanced-High / Frontier-Max capability tiers;
- keep risk routing independent and apply stronger gates without automatically increasing implementation cost;
- replace the V1 monolithic governance load with Lean, Controlled, and Strict references;
- prevent ordinary Workers from reloading the complete team Skill;
- default to one Writer and one Validator per repository and gate new Writers on integration backlog;
- add the main-agent-owned prospective JSONL ledger, JSON Schema, metrics handoff, and standard-library `record`, `snapshot`, `audit`, and `compare` CLI;
- update public examples, English README, and Chinese README.
