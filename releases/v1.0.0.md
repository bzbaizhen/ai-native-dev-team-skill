## Recovery check

To reconstruct the release:

```text
git -c core.autocrlf=false archive --format=zip --output=ai-native-dev-team-skill-v1.0.0-canonical.zip v1.0.0
```

Disabling `core.autocrlf` for this export prevents a Windows Git installation from rewriting LF to CRLF inside the ZIP. After extraction, run `python tests/validate_skill.py` and compare the installable payload against `releases/v1.0.0.sha256`.
